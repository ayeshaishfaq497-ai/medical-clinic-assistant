# 🏥 Medical Clinic AI Assistant

A professional AI-powered Medical Assistant built with **LangGraph**, **n8n**, and **Google Gemini**.

## ✨ Features
*   **Doctor Appointment Scheduling:** Automatically routes to n8n to book slots.
*   **Medical Knowledge Base (RAG):** Provides information about medicines and clinic policies.
*   **Smart Routing:** Understands if the user wants to book an appointment or just ask a question.

## 🛠️ Tech Stack
*   **Framework:** LangGraph
*   **Automation:** n8n
*   **AI Model:** Google Gemini
